# Notes – Day 2

## Apex

Apex is Salesforce's programming language used for implementing custom business logic.

### Uses:
- Data Processing
- Automation
- Complex Calculations
- Integrations

---

## SOQL

SOQL (Salesforce Object Query Language) retrieves data from Salesforce objects.

Example:

SELECT Name FROM Student__c

---

## Flow Builder

Flow Builder is a no-code automation tool.

Benefits:
- Reduces manual work
- Automates business processes
- Improves efficiency

---

## Apex Triggers

Triggers execute automatically when records are created, updated, deleted, or restored.

Examples:
- Send notifications
- Update related records
- Validate business rules

---

## Lightning Web Components

LWC is Salesforce's modern UI framework.

Benefits:
- Reusable Components
- Better Performance
- Modern Development Approach

---

## Security

Security ensures that users only access authorized information and actions.

Components:
- Profiles
- Roles
- Permission Sets
