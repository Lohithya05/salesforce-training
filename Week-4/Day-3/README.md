# Leave Management System

## Project Description

The Leave Management System is a Salesforce-based application that helps employees submit leave requests and allows administrators to approve or reject them.

## Objectives

- Reduce manual paperwork
- Simplify leave request management
- Track leave status efficiently
- Generate reports and dashboards

## Features

### Employee
- Submit Leave Request
- View Leave Status
- View Leave History

### Administrator
- Review Leave Requests
- Approve Leave
- Reject Leave
- View Reports
- View Dashboards

## Salesforce Components Used

- Custom Objects
- Custom Fields
- Tabs
- Page Layouts
- Approval Processes
- Reports
- Dashboards

## Custom Object

### Leave Request

Fields:
- Employee Name
- Employee ID
- Leave Type
- Start Date
- End Date
- Reason
- Status

## Approval Workflow

1. Employee submits leave request.
2. Status becomes Pending.
3. Admin reviews request.
4. Admin approves or rejects request.
5. Status is updated automatically.

## Project Outcome

A fully functional leave management application developed using Salesforce declarative tools without Apex programming.
