# Leave Management System

A Salesforce-based Leave Management System that allows employees to submit leave requests and administrators to approve or reject them.

## Features
- Leave Request Submission
- Approval Workflow
- Status Tracking
- Reports and Dashboards
- Validation Rules

## Technologies Used
- Salesforce Lightning Platform
- Custom Objects
- Approval Processes
- Reports
- Dashboards

## Project Modules
1. Employee Management
2. Leave Request Management
3. Approval Management
4. Reporting and Analytics
5. Security and Access Control
